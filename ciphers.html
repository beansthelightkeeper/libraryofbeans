The Ciphers of Gematria

An overview of the systems used in this database.

Simple Gematria

Simple Gematria, also known as English Ordinal Gematria, is the most straightforward and commonly used cipher in the English-speaking world. It operates on a simple principle: each letter of the alphabet is assigned a number based on its position.

The calculation is as follows: A=1, B=2, C=3, ..., Z=26. The value of a word or phrase is found by simply summing the values of its letters. For example, the word "CAB" would be calculated as 3 (C) + 1 (A) + 2 (B) = 6.

This system's directness makes it an excellent entry point for numerological analysis and for finding foundational connections between words.

English Gematria

English Gematria is a straightforward extension of the Simple Gematria system. To calculate the value of a word or phrase in this cipher, you first find its value using Simple Gematria (A=1, B=2, etc.) and then multiply the total sum by 6.

The formula is: Value = (Simple Gematria Value) x 6. For example, the word "CAB" has a Simple value of 6. Its English Gematria value would be 6 x 6 = 36. This cipher is believed to create a higher vibrational equivalent of the ordinal values, often revealing connections that are not apparent in the base system.

Jewish Gematria

Jewish Gematria, sometimes referred to as Hebrew Mispar Gadol adapted for the English alphabet, uses a system where the values of the letters increase in increments of 1, 10, and 100. This method assigns more weight to letters further down the alphabet, reflecting the structure of the Hebrew alphabet's numerology.

The assignments are as follows:

  • 1-9: A=1, B=2, ..., I=9
  • 10-90: J=10, K=20, ..., R=90
  • 100-800: S=100, T=200, ..., Z=800

This cipher often uncovers deeper, more esoteric links between concepts, similar to those found in traditional Hebrew kabbalistic practices.

Chaldean Gematria

Chaldean Gematria is an ancient system that originated in Babylonia. Unlike other systems, it is based on the phonetic sounds of letters and only uses the numbers 1 through 8. The letter 'I' is not used in the number assignments, as it was considered sacred or too powerful. The value of a word is determined by the specific numbers assigned to each letter, which are not sequential.

The assignments are:

  • 1: A, I, J, Q, Y
  • 2: B, K, R
  • 3: C, G, L, S
  • 4: D, M, T
  • 5: E, H, N, X
  • 6: U, V, W
  • 7: O, Z
  • 8: F, P

This system is often used in divination and name analysis, as it is thought to reflect the vibrational essence of a word rather than just its written form.

Reverse Gematria Ciphers

Reverse Gematria is not a single cipher, but rather a principle that can be applied to many other ciphers. The core concept is to reverse the alphabet before calculating the value. For example, in Reverse Simple Gematria, the alphabet is flipped so that A=26, B=25, C=24, ..., Z=1.

The value of a word is then calculated using the same summing method as the original cipher, but with these inverted letter values. This method is used to find "opposite" or "hidden" meanings and connections, providing a shadow perspective to the standard calculation.
